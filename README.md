## 📝 퀴즈 주제와 선정 이유

### 주제

**정보처리기사 필기 - 제1과목: 소프트웨어 설계**

이 프로젝트에서 사용하는 퀴즈는 정보처리기사 필기시험의 내용을 바탕으로 구성했습니다.

특히 여러 과목 중 제1과목인 **소프트웨어 설계** 분야의 문제를 중심으로 문제를 선택하였습니다.

### 선정 이유

정보처리기사 필기시험이 끝나고 학습한 내용을 실제 프로그램을 통해 반복해서 확인하고 복습할 수 있도록 정보처리기사를 퀴즈 주제로 선정했습니다.

그중에서도 **소프트웨어 설계 분야를 중심으로 구성한 이유는 앞으로 소프트웨어를 설계하고 구조화하는 능력의 중요성이 더욱 커질 것이라고 생각했기 때문입니다.**

단순히 코드를 작성하는 능력뿐만 아니라, 소프트웨어의 구조와 요구사항을 이해하고 적절한 설계 방법을 선택하는 능력이 중요해지는 시대가 오고 있다고 확신합니다.

따라서 소프트웨어 설계 관련 문제를 반복적으로 풀면서 해당 분야의 개념을 학습하고, 동시에 직접 만든 퀴즈 게임을 통해 학습 내용을 복습할 수 있도록 구성했습니다.

또한, 현재 개발 입문 단계에도 딱 맞는 주제라고 판단했습니다. 해당 분야를 접해보지 못했던 분들은 정보처리기사라는 자격증 자체를 어느 특정 분야의 가고자 하는 이들의 것이라고 생각하실 수도 있지만 점점 해당 자격증에 등장하는 개념들은 앞으로 그 어떤 분야에서 일하고자 하는 분이든 필수적인 기반 지식이 될 것이라고 봅니다.

비단 필기시험이 끝났다고 해서 필기에서 등장했던 개념이 실기시험에서 등장하지 않는 것은 아니므로, 반복 학습을 통해 낯선 용어는 눈에 익숙해지도록 유도하고, 실제 프로젝트와 과제를 진행할 때 적용시킬 수 있기를 바라면서 이러한 주제를 선정하게 되었습니다.
