# 🎯 나만의 퀴즈 게임

Python을 이용해 만든 **터미널 기반 콘솔 퀴즈 게임**입니다.

Python의 기본 문법과 객체 지향 프로그래밍, 파일 입출력, JSON 데이터 저장, 예외 처리를 직접 활용하여 하나의 프로그램을 처음부터 끝까지 구현하는 것을 목표로 제작했습니다.

또한 Git을 이용해 기능별로 작업 내용을 커밋하고 브랜치를 생성·병합하면서 프로젝트의 변경 이력을 관리했습니다.


## 📌 프로젝트 개요

이 프로젝트는 사용자가 터미널에서 퀴즈를 풀고, 새로운 퀴즈를 등록하며, 등록된 퀴즈 목록과 최고 점수를 확인할 수 있는 프로그램입니다.

프로그램을 종료한 이후에도 등록한 퀴즈와 최고 점수가 유지되도록 `state.json` 파일에 데이터를 저장합니다.

주요 학습 내용은 다음과 같습니다.

* Python 기본 문법
* 변수와 자료형
* 조건문과 반복문
* 함수와 매개변수
* 클래스와 객체
* 클래스의 속성과 메서드
* `try/except`를 이용한 예외 처리
* JSON 파일 입출력
* Git을 이용한 버전 관리
* Git branch 생성 및 merge

미션의 요구사항에 따라 최소 2개의 클래스를 사용하고 기능별로 메서드를 분리하여 프로그램을 구성했습니다.


## 📝 퀴즈 주제와 선정 이유

### 주제

**정보처리기사 필기 - 제1과목: 소프트웨어 설계**

이 프로젝트에서 사용하는 퀴즈는 정보처리기사 필기시험의 내용을 바탕으로 구성했습니다.

특히 여러 과목 중 제1과목인 **소프트웨어 설계** 분야의 문제를 중심으로 문제를 선택하였습니다.

### 선정 이유

정보처리기사 필기시험이 끝나고 학습한 내용을 실제 프로그램을 통해 반복해서 확인하고 복습할 수 있도록 정보처리기사를 퀴즈 주제로 선정했습니다.

그중에서도 **소프트웨어 설계 분야를 중심으로 구성한 이유는 앞으로 소프트웨어를 설계하고 구조화하는 능력의 중요성이 더욱 커질 것이라고 생각했기 때문입니다.**

단순히 코드를 작성하는 능력뿐만 아니라, 소프트웨어의 구조와 요구사항을 이해하고 적절한 설계 방법을 선택하는 능력이 중요해지는 시대가 오고 있다고 확신합니다.

따라서 소프트웨어 설계 관련 문제를 반복적으로 풀면서 해당 분야의 개념을 학습하고, 동시에 직접 만든 퀴즈 게임을 통해 학습 내용을 복습할 수 있도록 구성했습니다.

또한, 현재 개발 입문 단계에도 딱 맞는 주제라고 판단했습니다. 해당 분야를 접해보지 못했던 분들은 정보처리기사라는 자격증 자체를 어느 특정 분야의 가고자 하는 이들의 것이라고 생각하실 수도 있지만 점점 해당 자격증에 등장하는 개념들은 앞으로 그 어떤 분야에서 일하고자 하는 분이든 필수적인 기반 지식이 될 것이라고 봅니다.

비단 필기시험이 끝났다고 해서 필기에서 등장했던 개념이 실기시험에서 등장하지 않는 것은 아니므로, 반복 학습을 통해 낯선 용어는 눈에 익숙해지도록 유도하고, 실제 프로젝트와 과제를 진행할 때 적용시킬 수 있기를 바라면서 이러한 주제를 선정하게 되었습니다.

## 🚀 실행 방법

### 1. Python 버전 확인

Python 3.10 이상 환경에서 실행합니다.

```bash
python --version
```

또는 환경에 따라:

```bash
python3 --version
```

### 2. 프로젝트 실행

프로젝트 루트 디렉터리에서 다음 명령어를 실행합니다.

```bash
python main.py
```

또는:

```bash
python3 main.py
```

### 3. 메뉴 선택

프로그램이 실행되면 다음 메뉴가 표시됩니다.

```text
========================================
🎯 나만의 퀴즈 게임
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 최고 점수
5. 종료
========================================
```

원하는 메뉴의 번호를 입력하여 기능을 사용할 수 있습니다.

## ✨ 기능 목록

### 1. 퀴즈 풀기

등록되어 있는 퀴즈를 순서대로 풀 수 있습니다.

* 문제와 4개의 선택지를 출력
* 사용자가 정답 번호 입력
* 정답/오답 여부 출력
* 모든 문제를 푼 후 점수 출력
* 기존 최고 점수보다 높은 경우 최고 점수 갱신
* 퀴즈가 없는 경우 안내 메시지 출력

---

### 2. 퀴즈 추가

새로운 퀴즈를 직접 등록할 수 있습니다.

입력 항목:

* 문제
* 선택지 1
* 선택지 2
* 선택지 3
* 선택지 4
* 정답 번호

등록한 퀴즈는 `state.json`에 저장되어 프로그램을 다시 실행해도 유지됩니다.

---

### 3. 퀴즈 목록

현재 저장되어 있는 모든 퀴즈의 문제를 확인할 수 있습니다.

```text
퀴즈 목록

1. 객체지향 설계 원칙 중 서브타입(상속받은 하위 클래스)은\n어디에서나 자신의 기반타입(상위 클래스)으로\n교체할 수 있어야 함을 의미하는 원칙은?
2. 객체지향 소프트웨어 공학에서 하나의 이상의\n유사한 객체들을 묶어서 하나의 공통된 특성을 표현한 것은?
3. UI 설계 원칙 중 누구나 쉽게 이해하고 사용할 수 있어야 한다는 원칙은?
...
```

퀴즈가 없는 경우에는 안내 메시지를 출력합니다.

---

### 4. 최고 점수

현재까지 기록된 최고 점수를 확인할 수 있습니다.

최고 점수는 `state.json`에 저장되기 때문에 프로그램을 종료하고 다시 실행해도 유지됩니다.

---

### 5. 종료

프로그램을 종료하기 전에 현재 퀴즈와 최고 점수를 저장한 후 안전하게 프로그램을 종료합니다.

---

## 🛡️ 입력 및 예외 처리

프로그램에서는 잘못된 입력으로 인해 프로그램이 종료되지 않도록 예외 처리를 적용했습니다.

### 숫자가 아닌 값을 입력한 경우

```text
선택: abc
숫자를 입력하세요.
```

안내 메시지를 출력하고 다시 입력할 수 있습니다.

### 허용 범위를 벗어난 숫자를 입력한 경우

```text
선택: 9
1 ~ 5 입력
```

메뉴에서 허용하지 않는 숫자를 입력하면 다시 입력할 수 있습니다.

### 빈 입력

Enter만 입력한 경우 다시 입력하도록 처리합니다.

### `KeyboardInterrupt`, `EOFError`

프로그램 실행 중 `Ctrl+C` 또는 입력 스트림 종료가 발생한 경우 안내 메시지를 출력하고 데이터를 저장한 뒤 종료하도록 처리했습니다.

### `state.json`이 없는 경우

처음 프로그램을 실행하여 저장 파일이 존재하지 않는 경우 기본 퀴즈 데이터를 생성하여 사용합니다.

### `state.json`이 손상된 경우

JSON 파일을 정상적으로 읽을 수 없는 경우 기본 퀴즈 데이터로 복구하도록 처리했습니다.

### `main.py`

프로그램의 시작점입니다.

`QuizGame` 객체를 생성하고 게임을 실행합니다.

```python
game = QuizGame()
game.run()
```

---

### `Quiz.py`

개별 퀴즈를 표현하는 `Quiz` 클래스를 정의합니다.

주요 속성:

* `question` : 문제
* `choices` : 선택지
* `answer` : 정답 번호

주요 메서드:

* `display()` : 문제와 선택지 출력
* `check_answer()` : 사용자의 답이 정답인지 확인
* `to_dict()` : 퀴즈 객체를 딕셔너리 형태로 변환
* `from_dict()` : 딕셔너리 데이터를 `Quiz` 객체로 변환

---

### `QuizGame.py`

게임 전체의 흐름을 관리하는 `QuizGame` 클래스를 정의합니다.

주요 속성:

* `quizzes` : 퀴즈 목록
* `best_score` : 최고 점수

주요 기능:

* 메뉴 출력
* 퀴즈 풀기
* 퀴즈 추가
* 퀴즈 목록 출력
* 최고 점수 확인
* JSON 데이터 저장
* JSON 데이터 불러오기
* 사용자 입력 및 예외 처리

---

### `state.json`

프로그램의 데이터를 저장하는 JSON 파일입니다.

프로젝트 루트에 위치하며 다음 데이터를 저장합니다.

* `quizzes` : 저장된 퀴즈 목록
* `best_score` : 최고 점수

---

## 💾 데이터 파일 설명

### 파일 경로

```text
프로젝트 루트/state.json
```

### 데이터 형식

`state.json`은 JSON 형식으로 데이터를 저장합니다.

현재 프로젝트의 데이터는 다음과 같은 구조를 사용합니다.

```json
{
    "quizzes": [
        {
            "question": "객체지향 설계 원칙 중 서브타입(상속받은 하위 클래스)은\n어디에서나 자신의 기반타입(상위 클래스)으로\n교체할 수 있어야 함을 의미하는 원칙은?\n",
            "choices": [
                "ISP(Interface Segregation Principle)",
                "DIP(Dependency Inversion Principle)",
                "LSP(Liskov Substitution Principle)",
                "SRP(Single Responsibiliy Principle)"
            ],
            "answer": 3
        }
}
```

실제 `state.json`에도 `quizzes`와 `best_score`가 저장되어 있으며, 기본 퀴즈는 5개가 등록되어 있습니다.

### `quizzes`

퀴즈 데이터를 저장하는 배열입니다.

각 퀴즈는 다음과 같은 정보를 가집니다.

| 필드         | 설명      |
| ---------- | ------- |
| `question` | 퀴즈 문제   |
| `choices`  | 4개의 선택지 |
| `answer`   | 정답 번호   |

### `best_score`

사용자가 퀴즈를 풀었을 때 기록한 최고 점수를 저장합니다.

## 🧱 클래스 구조

프로그램은 역할에 따라 `Quiz`와 `QuizGame` 클래스로 나누어 구성했습니다.

```text
Quiz
│
├── question
├── choices
├── answer
│
├── display()
├── check_answer()
├── to_dict()
└── from_dict()


QuizGame
│
├── quizzes
├── best_score
│
├── create_default_quizzes()
├── save_data()
├── load_data()
├── get_number_input()
├── show_menu()
├── play_quiz()
├── add_quiz()
├── show_quizzes()
├── show_best_score()
└── run()
```

`Quiz`는 **개별 퀴즈 하나의 데이터와 동작**을 담당하고, `QuizGame`은 **여러 퀴즈와 게임 전체의 흐름**을 담당하도록 역할을 분리했습니다.
